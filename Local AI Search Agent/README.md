# 🤖 Local AI Search Agent | Yerel Yapay Zeka Arama Ajanı

This project is a completely free, locally running AI agent that can search the internet to provide up-to-date answers. It uses *Llama 3.2* as the brain and *DuckDuckGo* for real-time web search.

Bu proje, güncel cevaplar sunmak için internette arama yapabilen, tamamen ücretsiz ve yerel olarak çalışan bir yapay zeka ajanıdır. Beyin olarak *Llama 3.2, gerçek zamanlı web araması için ise **DuckDuckGo* kullanır.

---

## 🚀 Features | Özellikler

- *100% Free:* No API keys or paid subscriptions required. (Tamamen Ücretsiz: API anahtarı veya ücretli abonelik gerektirmez.)
- *Privacy Focused:* Your prompts are processed locally on your machine using Ollama. (Gizlilik Odaklı: Sorularınız Ollama aracılığıyla yerel cihazınızda işlenir.)
- *Internet Access:* Can search the web for real-time information. (İnternet Erişimi: Gerçek zamanlı bilgiler için web'de arama yapabilir.)
- *Hardware Optimized:* Runs efficiently on modern hardware (Optimized for Intel Core Ultra / Arc GPU). (Donanım Optimize Edildi: Modern donanımlarda verimli çalışır.)

---

## 🛠️ Requirements | Gereksinimler

- [Ollama](https://ollama.com/)
- Python 3.10+
- Llama 3.2 model (ollama pull llama3.2)

---

## 📦 Installation | Kurulum

1. *Clone the repository | Depoyu kopyalayın:*

   git clone 
   cd Local-AI-Search-Agent
Install dependencies | Bağımlılıkları yükleyin:

pip install langchain langchain-ollama langchain-community duckduckgo-search
Run the agent | Ajanı çalıştırın:

python ajan.py
